# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) v2.1.

In short: be respectful, assume good faith, and focus on the work. Harassment or exclusionary behaviour of any kind is not welcome.

To report a conduct issue, contact the maintainers via a private GitHub message or email found on the maintainer's profile.
